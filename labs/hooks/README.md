# Prototypes

One directory per idea, named by a short id: `labs/hooks/<id>/README.md`, `src/` and `test/`. Copy a template from [`../templates`](../templates) to start, keep the test, and write the README before the code: what the hook or module does on a swap, what it takes and from whom, and what the tests do not yet show.

Nothing in this directory is deployed, listed or admitted anywhere by being merged.
